# Server IP resolution

## Goal
Resolve the daemon's public IP once per startup without waiting on a remote request, persist it locally, and expose the current value for future DNS work.

## Decisions
- `SERVER_IP` overrides discovery and cached state; validate IPv4/IPv6.
- Otherwise load local cached state, then refresh remotely in the background with a short timeout.
- Save successful discoveries atomically and retain the previous value on discovery failure.
- Log discovery start, outcome, and elapsed time.
- Use existing dependencies and runtime facilities. No Cloudflare integration in this change.

## Approach
Integrate a small IP-resolution component with daemon configuration and lifecycle. Keep network/state dependencies testable; cancel pending discovery on shutdown. Follow existing deployment state-directory conventions and document the cache location.
